Nine editable Elementor widgets matching the EduMatchup Modern homepage and destinations page.

== Description ==

Includes Hero, Destinations, Services, Arrival Support, Process Steps, Study Tools, and Call to Action widgets. Repeatable cards, services, steps, and links can be added, removed, and reordered in Elementor. Typography, colors, spacing, and responsive layout controls are provided.

== Requirements ==

* WordPress 6.0 or later
* PHP 7.4 or later
* Elementor (free) installed and active

The theme ZIP supplied for reference declares PHP 8.1 as its own requirement. This addon declares PHP 7.4, but does not lower the theme's requirement.

== Author ==

Developed by PlayWithPPC.

== Homepage template ==

Import templates/edumatchup-homepage.json under Templates → Saved Templates → Import Templates. Edit the Home page in Elementor and insert the imported EduMatchup Homepage template. This does not automatically replace the site's front page.

== Destinations page template ==

Import templates/edumatchup-destinations.json under Templates → Saved Templates → Import Templates. Insert EduMatchup Destinations Page on the Destinations page. The template has an editable page intro and filterable destination directory, without a CTA.

== Updates ==

Updates are checked from the public GitHub Releases page. Publish a versioned release and attach an asset named edu-matchup-elementor-addons.zip. The archive must include the edu-matchup-elementor-addons folder at its root.
